# AI Operator

AI Operator 是一个 Windows 可执行程序，读取指定窗口画面，交给视觉模型判断，再模拟键盘和鼠标执行判断结果，适合回合制、RPG、卡牌、策略、开放世界探索这类节奏不快的游戏

> 它会模拟真实键鼠输入，可能违反游戏条款并导致账号被封，首次运行必须阅读并确认《免责声明》与《用户使用协议》，请先判断自己能否接受这些风险，并自行确认所属游戏的用户协议允许此类操作

## 亮点

- **单文件免安装**：一个 360 KB 的 exe，只依赖系统自带的 .NET Framework 4.8，删掉文件就是卸载
- **动作名驱动**：模型说的是“技能”“跳跃”“交互”，不用自己编键值，改键位只动“动作”表，提示词不用改
- **不绑定模型厂商**：接口地址与模型名都能改，默认 DeepSeek，换成任何兼容 Chat Completions 的服务也能跑
- **动作表白名单**：只有表里启用的键会被按下，表外的键会让程序停下来
- **走位标定**：把“走 1 米需要多少毫秒”调准，模型就能直接说“前进 1 米”，而不是瞎按
- **移动滑行**：移动结束后多按一小段，把等模型回复的空档补上，缓解画面里走走停停
- **鼠标灵敏度标定**：转身按度数换算成横向位移，不需要自己算像素
- **叠加层可拖动**：按住热键时叠加层变成可拖动，松手记住位置，不再挡视野
- **每日预算**：按公开价目估算当天花费，到顶自动暂停
- **急停**：F10 随时松开所有按下的键和鼠标
- **省钱的跳过**：画面没变化时不发请求
- **密钥只存本机**：用 Windows DPAPI 加密，换一个 Windows 账户就解不开
- **首次运行强制确认协议**：主界面被磨砂遮罩盖住，确认窗口关不掉，三项勾选才能进
- **版本检查失败放行**：断网、仓库不可达都不会把人挡在门外

## 下载与运行

1. 下载 `AI-Operator-v1.1-win64.exe`（约 360 KB）
2. 双击运行，程序没有代码签名，Windows 可能提示“已保护你的电脑”，点“更多信息” → “仍要运行”
3. 第一次运行会弹出协议窗口，勾选三项后才能进入主界面，这个窗口关不掉，只能同意或退出
4. 免安装，删掉 exe 就是卸载

想核对下载是否完整，Release 说明里附了完整的 SHA256，可以用 `certutil -hashfile 文件名 SHA256` 对一下

## 第一次使用

1. **连接**：粘贴 API Key（`sk-` 开头），点“测试连接”，返回“通了”说明接口可用
2. **游戏**：把游戏切成**无边框窗口模式**，点“刷新列表”选中它，点“抓一帧”确认预览不是黑屏
3. **说明**：在“AI”页写清游戏名、界面布局、目标是什么，这段文字每一轮都会发给模型
4. **标定**：在“动作”页把“走 1 米需要多少毫秒”调到接近实际，或者点“试走 1 秒”看走了多远再反推
5. 按 **F8** 开始，先盯着看几轮，确认“日志”页里执行的动作和游戏里发生的一致

## 热键

全局生效，游戏在前台时也能用

| 键 | 作用 |
|---|---|
| F8 | 开始 / 暂停 |
| F9 | 接管 / 交还（接管期间程序不动键鼠） |
| F10 | 紧急停止，立即松开所有按键与鼠标 |
| F11 | 让模型立刻重新读取画面 |
| F12 | 叠加层开关 |
| F7 | 按住不放，叠加层变成可拖动，松手记住位置 |

热键可以在“热键”页点方块后重新绑定，改完立即生效

## 它是怎么操作的

模型每轮返回的不是“按一下 W”，而是带时长的动作序列，按键一律用动作名

```json
{"thought":"前方有箱子，先走过去","actions":[
  {"do":"walk","dir":"forward","meters":1.0},
  {"do":"act","name":"技能"},
  {"do":"click","x":0.52,"y":0.61}
]}
```

- `act` 按动作名去“动作”表里查键值和按住时长，模型不需要知道具体是哪个键，换键位不用改提示词
- `walk` 按标定换算成按住时长，默认 620ms 对应 1 米
- `turn` 与 `look` 按鼠标灵敏度换算成横向位移，转之前会先把光标拉回窗口中心
- 同一次回复里连续的移动会合并成一次长按，避免走一步松一次键
- 最后一个动作是移动时，会多按“移动滑行”那么多毫秒，把等模型回复的空档补掉一部分
- 每轮之间要等模型回复 0.5 到 2 秒，这期间角色是静止的，所以提示词要求单次移动不少于 1.2 秒，长距离用 down 与 up 覆盖思考时间

## 版本检查

启动后会在后台读一次仓库里的 `version.json`，每天最多一次，结果缓存在本机

| 情况 | 表现 |
|---|---|
| 有比当前新的版本 | 右上角出现可关闭的提示条，不挡操作 |
| 最低支持版本高于当前 | 界面被遮罩盖住，弹出不可关闭的更新窗口 |
| 请求失败或断网 | 什么都不弹，照常使用 |

启动时加 `--skip-update-check` 可以跳过检查

## 数据与隐私

程序不设服务器，除了一次版本号请求之外不主动联网，数据都留在本机

```text
%APPDATA%\AIOperator\
├─ config.json  配置（模型、动作表、窗口句柄等）
├─ key.bin      API Key，DPAPI 加密，换账户无法解密
├─ cost.txt     当日估算花费
├─ legal.json   协议确认记录
├─ update.json  版本检查缓存
└─ operator.log 运行日志
```

运行过程中，目标窗口的截图会连同你填写的说明文字一起发到**你自己配置**的接口，是否保存、保存多久由该服务商决定

删除 `%APPDATA%\AIOperator\` 这个文件夹等于重置软件

## 常见问题

**预览是黑屏**
游戏的独占全屏模式截不到画面，改成无边框窗口模式，把窗口置前再抓一帧，少数带反作弊的游戏会直接拒绝截图

**按 F8 没有反应**
先看左侧状态是否变成“运行中”，没有变化通常是热键被游戏占用，去“热键”页换一个键

**角色走起来一顿一顿**
每轮要等模型回复，这 1 到 2 秒里程序不按键，所以会走走停停
现在有三层缓解：同批连续移动会合并成长按、单次按住上限 8 秒、最后一段多按“移动滑行”那么多毫秒
还觉得碎，就把“移动滑行”从 400 调到 800 甚至 1200，代价是停下时会稍微走过头

**AI 只用走路，不用技能和跳跃**
1.1 起按键改成按动作名执行，提示词也要求优先用“动作”表里的名字
如果还是不用，在“游戏说明”里写清“遇到敌人先放技能、障碍物前跳过去”，模型会照着做

**AI 转不动视角**
程序每次转视角前会把光标拉回游戏窗口中心，避免光标贴住屏幕边缘后位移被吞掉
如果这个游戏必须按住右键拖动才能转镜头，打开“AI”页的“转视角时按住右键”
还不行就在“日志”页看每轮有没有“转动视角”，完全没有是模型没发这个动作，有但画面不动是本游戏过滤了注入的鼠标

**杀毒软件报毒**
程序没有签名，又会模拟键鼠与截取画面，容易被启发式引擎误判，可以加白名单

**费用比预期高**
降低图片精度、加大每轮间隔、打开“画面没有变化时跳过请求”，都能明显降低花费

## 已知限制

- 云端视觉每轮耗时 0.5 到 2 秒，做不到射击游戏那种跟枪与压枪
- 独占全屏、HDR、多显示器缩放异常时，截图可能偏黑或变形
- 部分游戏的反作弊会拒绝截图或注入输入，这类情况没有可靠解
- 只提供 64 位版本，32 位系统跑不了
- 还没做：多套配置方案切换、日志导出、弹幕互动
